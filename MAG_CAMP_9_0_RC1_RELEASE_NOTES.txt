MAG CAMP Enterprise 9.0 RC1
===========================

الأساس
- مبني على نسخة 8.3.3 المرفقة مع قاعدة 7.3 المستقرة داخل data/mhoms.db.
- قاعدة المصدر المرفقة تم التحقق منها: 4,375 عامل، 974 غرفة، 20 حسابًا.

الإصلاحات الرئيسية
1) استعادة بيانات الإنتاج
- إضافة production_recovery.py.
- عند اكتشاف PostgreSQL فارغًا أو ناقصًا بشدة، تتم استعادة قاعدة 7.3 كاملة تلقائيًا.
- تتم مطابقة الجداول والأعمدة قبل النسخ.
- يتم استبدال البيانات الجزئية المزروعة فقط عندما تكون الجداول الحرجة ناقصة.
- تحقق نهائي إلزامي لعدد العمال والغرف قبل اعتماد الاستعادة.

2) إدارة الطلبات
- إظهار زر مستقل وواضح «تسكين جديد».
- إظهار زر «نقل عامل بين الغرف».
- دعم فتح نموذج الطلب مباشرة على النوع المطلوب.

3) بلاغات عدم التواجد
- إعادة زر «رفع بلاغ عدم تواجد جديد» أعلى صفحة المتابعة.

4) الإصدار
- تحديث اسم النظام إلى Enterprise 9.0 RC1.

سجلات Render المطلوبة بعد أول تشغيل

ملاحظات النشر
- لا تحذف DATABASE_URL.
- لا تحذف قاعدة Supabase.
- ارفع محتويات هذا المجلد إلى GitHub ثم Manual Deploy.
- الاستعادة الكاملة تعمل فقط إذا كانت جداول workers/rooms فارغة أو ناقصة بشدة، لحماية قاعدة سليمة من الاستبدال.

الاختبارات المنفذة
- فحص سلامة صياغة Python: ناجح.
- فحص قاعدة SQLite وأعداد السجلات: ناجح.
- تعذر تشغيل Flask محليًا في بيئة الإنشاء لعدم توفر تنزيل الحزم من الإنترنت؛ لذلك يلزم اختبار التشغيل الفعلي على Render.
